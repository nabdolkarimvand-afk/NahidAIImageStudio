# Nahid AI Image Studio v4

این نسخه برای Redmi Note 12 / Snapdragon 685 طراحی شده است.

## مدل پیشنهادی
DreamShaper-7 + LCM Q4_0 به صورت GGUF، حدود 1.63 GB. این مدل برای stable-diffusion.cpp آماده شده و برای 512x512 و 6 steps با LCM توصیه شده است.

مدل بعد از نصب از داخل برنامه دانلود می‌شود؛ APK عمداً مدل 1.63GB را داخل خود ندارد.

## استفاده
1. APK را نصب کنید.
2. به اینترنت/Wi-Fi وصل شوید.
3. Download recommended model را بزنید و صبر کنید تا 100% شود.
4. بعد از دانلود می‌توانید اینترنت را خاموش کنید.
5. Prompt، ابعاد، steps و seed را انتخاب کنید و Generate را بزنید.

## ابعاد
برای Snapdragon 685 ابتدا 512x512 یا 768x432 را پیشنهاد می‌کنیم. 1024x576 و 576x1024 ممکن است بسیار کند باشند.

## توجه
نسخه فعلی موتور را با ARM64/CPU می‌سازد. پشتیبانی OpenCL/Adreno در مرحله بعدی می‌تواند جداگانه اضافه و روی خود Redmi Note 12 بنچمارک شود.
